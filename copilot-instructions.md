# Copilot Instructions
- Do not make any changes until you are 95% confidence on what you need to build, ask me follow-up questions until you reach that confidence.
- Prefer small, direct changes.
- Do not introduce new dependencies without asking.
- Reuse existing project patterns before suggesting alternatives.
- Output concise diffs, not full-file rewrites unless requested.
- If context is missing, ask for the specific file or log instead of scanning broadly.
- do not scan a full repo, always ask about the target files.
- Prefer safe defaults, explicit error handling, and reversible changes.
